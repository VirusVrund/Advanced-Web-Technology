# To-Do List App (Flask)

## Functionalities
1. Add new tasks
2. Mark tasks as complete/incomplete
3. Delete tasks
4. View task count

## Run Steps
1. Open terminal in this folder.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start app:
   ```bash
   python app.py
   ```
4. Open in browser:
   ```
   http://127.0.0.1:5000
   ```
